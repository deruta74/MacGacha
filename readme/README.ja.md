> ✨ **[MacGacha 0.2.0](https://github.com/deruta74/MacGacha/releases/tag/v0.2.0) を公開しました**。ベータ表記のない初めてのリリースです。14 言語、HoYoPlay 風の背景とイベント、『原神』のフレームレート上限解除、『崩壊：スターレイル』の 120 FPS、空間オーディオ対応のサラウンド、ゲームモードに対応しています。すでに 0.1.x をお使いの場合は、MacGacha が自動更新します。気になる点があれば[ご報告ください](#feedback)。

Apple Silicon で **『原神』**、**『崩壊：スターレイル』**、**『ゼンレスゾーンゼロ』** を利用するための、macOS ネイティブのランチャーです。HoYoverse の公式サーバーからゲームをインストール、更新、検証し、Wine / DXMT / D3DMetal の実行環境を管理して、各ゲームをワンクリックで起動します。

- 動作要件：Apple Silicon 搭載 Mac、Rosetta 2（MacGacha からインストールを案内します）、macOS 27 以降。

このリポジトリのコードやドキュメントは、大規模言語モデル（LLM）や AI エージェントの支援を受けて作成・変更される場合があります。本ソフトウェアは [GPL-3.0 ライセンス](../LICENSE)の下、無保証の現状有姿で提供されます。

## インストール

1. [Releases](https://github.com/deruta74/MacGacha/releases) から `MacGacha-<version>.dmg` をダウンロードして開き、**MacGacha** を**アプリケーション**にドラッグします。
2. MacGacha を開きます。アプリは Apple による署名・公証を受けていないため、macOS に開発元を確認できない旨が表示されます。**完了**をクリックします。
3. **システム設定 → プライバシーとセキュリティ**を開き、MacGacha に関するメッセージまでスクロールして、**このまま開く**をクリックし、確認します。

**このまま開く**ボタンがない場合や、macOS が引き続きアプリの起動を拒否する場合は、ターミナルでダウンロードの隔離属性を削除してから、MacGacha を再度開いてください。

```bash
xattr -dr com.apple.quarantine /Applications/MacGacha.app
```

この操作で変更されるのは MacGacha 自体だけで、システム設定は変更されません。初回起動は macOS によるアプリの確認のため、時間がかかる場合があります。

以降のバージョンは MacGacha メニューの**アップデートを確認…**から入手できるため、この手順は一度だけ必要です。

## ロードマップ

**実装済み**

- **ワンクリックでプレイ。** 「ゲーム開始」を押すと、ランチャーが Wine プレフィックスと互換性のための回避策を準備してゲームを起動し、Dock に最小化します。ゲームが終了すると再表示され、隠していたゲームファイルを元に戻します。3 タイトルすべてで、D3DMetal と DXMT の動作確認・受け入れ検証を完了しています。
- **ゲームのインストール。** HoYoverse の公式配信システムを使ったインストール、更新、検証、修復、音声パックの管理、既存インストールの利用、アンインストールに対応しています。一時停止と再開はアプリを再起動しても有効です。ダウンロード前と実行中に空き容量を確認します。macOS がまだ領域を確保している場合（Time Machine のスナップショットやキャッシュなど）は、単に「空き容量が足りません」と表示せず理由を説明します。ゲームメニューの**アップデートを確認**ですぐに新しいバージョンを確認できます。
- **ダウンロードエンジン。** 中断からの再開、ファイル検証、クラッシュに備えたジャーナルに対応しています。ハッシュが一致したファイルだけがゲームフォルダに入ります。ファイルを並列でダウンロード・組み立てし、2.5 Gbit/s 回線の上限に近い速度を出せます。ダウンロードと完全検証では残り時間を、長い処理では経過時間を表示します。
- **ランチャー。** 3 タイトルを 1 つのウインドウで管理し、HoYoPlay の背景を元の順序で表示します。MacGacha を開くたびに次の背景に進み、上部のドットでも切り替えられます。動画背景は MacGacha 独自のプレーヤーで再生し、Web ビューよりメモリ使用量を約 3 分の 1 削減しています。各背景のバージョンの見どころや、HoYoPlay の現在のイベントはブラウザで開きます。
- **『原神』のフレームレート上限解除（任意）。** 『原神』のゲーム設定にあるスイッチで、初期状態ではオフです。目標は 120 FPS、または最大 360 FPS までの任意の値に設定できます。MacGacha はゲームに小さな補助モジュールを読み込み、[genshin-fps-unlock](https://github.com/34736384/genshin-fps-unlock) の方式でフレームレート上限だけを引き上げます。独自に再現可能なビルドを行っています（[リリース](https://github.com/deruta74/MacGacha/releases/tag/genshin-fps-unlock-2)）。初めて有効にする際は、アカウント停止のリスクを警告します。グローバル版『原神』7.1 で検証し、3.5 時間のオンラインプレイ中に 120 FPS を維持しました。
- **『崩壊：スターレイル』を 120 FPS でプレイ。** グローバル版と中国本土版のゲーム設定にスイッチがあり、起動するたびにゲーム自身が保存するフレームレートを 120 に設定します。新規インストール後は、ゲーム内のグラフィック設定をどれか一度変更して設定を保存させてから、もう一度起動してください。
- **サラウンドサウンド。** 『原神』と『ゼンレスゾーンゼロ』は D3DMetal でサラウンド出力が可能で、AirPods などの対応ヘッドフォン向けに空間オーディオへミックスします。6 チャンネル以上のスピーカーは元のチャンネル構成を維持します。初期状態ではオフで、ゲームごとに切り替えられます。
- **ゲームモード。** macOS はゲームに対してゲームモードを有効にし、ランチャー自体には適用しません。各ゲームは名前とアイコンを持つ独立したアプリとして動作するため、macOS が認識できます。D3DMetal と DXMT で確認済みです。設定で無効にできます。
- **ゲームごとの設定：** グラフィックバックエンド、フレームレート制限（オフ、30、60、90、120）、ディスプレイ、Retina モード、『ゼンレスゾーンゼロ』用 DirectX 12、互換性のための回避策の切り替え。
- **実行環境。** Wine、DXMT、D3DMetal はダウンロード後も別々に保持するため、更新によって動作中のバージョンを壊しません。D3DMetal は Apple の規約に同意してからインストールするか、既存の Game Porting Toolkit から読み込みます。標準の DXMT ビルドは CrossOver の Wine を使用し、CPU 使用量は以前のビルドの約 1/2.5 です。
- **ワンクリック設定。** ゲームに実行環境が必要な場合、「セットアップ…」に現在の設定で必要なコンポーネントを正確に表示し、まとめてインストールします。Apple の規約への同意は D3DMetal が含まれる場合にだけ求めます。実行環境パネルから手動でバージョンを選ぶこともできます。
- **互換性コンポーネント。** jadeite と Steam ランチャーの代替プログラム（shim）は、実行環境ウインドウでインストール・削除できます。shim は Valve の Proton ソースから独自に再現可能なビルドを行っています（[リリース](https://github.com/deruta74/MacGacha/releases/tag/steam-shim-proton-10.0-4)）。
- **言語。** インターフェースは英語、簡体字・繁体字中国語、日本語、韓国語、ロシア語、ウクライナ語、ドイツ語、フランス語、スペイン語、ポルトガル語、インドネシア語、タイ語、ベトナム語に対応しています。Mac の言語の優先順位に従うほか、設定で選択できます。ゲームのニュースや画像もインターフェースの言語に従います（HoYoPlay にウクライナ語がないため、ウクライナ語では英語を使用します）。言語を変更すると MacGacha が再起動し、進行中のダウンロードは自動的に再開されます。
- **自動アップデート**（Sparkle）。MacGacha メニューに**アップデートを確認…**があり、設定にもスイッチがあります。更新のダウンロード前に確認し、ゲーム、復元、インストールのいずれも実行していないときにだけ更新をインストールします。更新ウインドウには変更内容が表示されます。
- **復元。** ゲーム実行中にランチャーがクラッシュしたり終了したりしても、次回起動時にゲームを再検出し、ゲーム終了後にすべて元に戻します。ゲーム実行中にランチャーを終了する際は確認を求めます。
- **プライバシー。** ゲームはそれぞれ独立した Wine プレフィックス内で動作し、デスクトップ、書類などのホームフォルダへのリンクはありません。セッションログは Mac 内にのみ保存され、設定で無効にできます。不具合報告用の診断バンドルからはパスとトークンを除去します。

**手動で動作確認済み（macOS 27.0.1）**

3 タイトルとも、コミュニティ製のアンチチート回避策を使って起動・プレイできます。`/etc/hosts` の変更や管理者権限は必要ありません。M5 Pro（48 GB）搭載の 14 インチ MacBook Pro と、標準構成の M5（16 GB）で測定しました。『ゼンレスゾーンゼロ』は両機で同じグラフィックプリセットを使用しています。

| ゲーム | 標準バックエンド | M5 Pro、48 GB | M5、16 GB |
|---|---|---|---|
| 崩壊：スターレイル 4.6 | D3DMetal、60 FPS 制限 | ウルトラ設定で 60 FPS。CPU 使用量は DXMT の約半分、GPU 時間は約 6.5 ms（DXMT は約 9 ms）。 | 未測定。 |
| ゼンレスゾーンゼロ | D3DMetal、DirectX 12 | 高設定で 120 FPS、戦闘中の低下時も 115 FPS を上回る。レイトレーシングを低にすると 70–90 FPS。 | 高設定の戦闘中は、画面内の敵やエフェクトの数に応じて 70–110 FPS。レイトレーシングを低にすると 50–60 FPS。 |
| 原神 7.1 | D3DMetal、60 FPS 制限 | ウルトラ設定、1800×1169、レンダリング精度 1.2 で安定した 60 FPS、フレーム時間も均一。上限解除時は 120 FPS。 | 1512×982、レンダリング精度 1.2 で 60 FPS。 |

DXMT はすべてのゲームで利用でき、オープンソースの選択肢として引き続き提供します。60 FPS 制限により『崩壊：スターレイル』と『原神』のフレーム間隔のばらつきを改善でき、制限はゲームごとに変更できます。

## フィードバック

不具合やアイデアがあれば、[Issue を作成](https://github.com/deruta74/MacGacha/issues)し、行った操作と結果、Mac の機種、macOS のバージョン、ゲーム名、使用したグラフィックバックエンドをお知らせください。インストールや起動に関する問題には、診断バンドルを添付してください。サイドバーの**診断** → **診断バンドルをエクスポート…**から作成できます。パスとトークンは除去されます。

## 安全性について

自己責任でご利用ください。Wine 上でゲームを動かすため、MacGacha はコミュニティ製のアンチチート回避策（jadeite、Steam ランチャーの shim）を使用しています。HoYoverse の利用規約に抵触する可能性があり、可能性は低くてもアカウント停止のリスクがあります。心配な場合は、まず新しい無料アカウントで試してください。

標準の動作では、MacGacha は HoYoverse の公式サーバーからのみゲームをダウンロードし、すべてのファイルを検証します。ゲームプロセスを変更せず、`/etc/hosts` を編集したり、パスワードを求めたりすることもありません。各ゲームは独立した Wine プレフィックスで動作し、デスクトップや書類にはアクセスできません。『原神』のフレームレート上限解除など、ゲームプロセスを変更する任意の機能は**初期状態ではオフ**です。初めて有効にする前に、MacGacha は追加のアカウント停止リスクを警告します。
