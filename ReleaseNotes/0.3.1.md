# MacGacha 0.3.1

- **Metal HUD.** A switch in each game's settings shows the frame rate, frame time and GPU load over the game. On D3DMetal, Shift-F9 hides or shows it while you play.
- **Play time.** The line above Play shows how long you have played each game, and the game's menu shows the last session. Only time the game was actually running counts, and your earlier sessions from MacGacha's log are included. It stays on your Mac.
- **Games on external drives.** If the drive with a game is disconnected, the game shows which drive to connect instead of looking uninstalled. A download or update on that drive pauses and continues with Resume once the drive is back.
- **Move a game.** **Move…** in a game's menu moves it to another folder or drive. On the same drive it's instant. To another drive, MacGacha copies the game, checks every file and only then removes the old folder. A pre-download moves with the game. If you cancel or a drive is disconnected before the copy finishes, the game stays where it was.
