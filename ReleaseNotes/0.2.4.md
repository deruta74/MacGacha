**Runtime updates without an app update.** MacGacha now checks for compatible runtime component updates independently. Install a chosen version through Set Up in Runtimes; the current working version stays selected until installation succeeds. New compatibility profiles still require an app update.

**Keep a working version.** Installed older versions remain available. Choosing an earlier version in Runtimes pins that choice. Use Keep This Version to pin your current version. You can return to the recommended version whenever you choose. Old versions are removed only when you explicitly remove them.

**Dialogue with Surround enabled.** Fixed a CoreAudio setup failure that could make dialogue disappear in Genshin Impact. If spatial audio cannot be initialized, multichannel audio now falls back to stereo while preserving dialogue channels.

To apply the audio fix, open Runtimes and use Set Up for Surround Audio revision 2 (`surround-audio-wine-11.20-2`), or select it if already installed. An existing revision 1 installation stays selected until you make this change.
