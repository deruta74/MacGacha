# MacGacha 0.3.4

- **Any download speed.** The download limit in Settings is now a switch with a field for your own value in MB/s, instead of a few fixed choices.
- **Opens on your last game.** The launcher opens on the game you last opened or started, including a start from a shortcut or the Dock menu.
- **Dock icon while a game starts.** MacGacha's Dock icon shows a spinning badge from Play until the game window appears. This helps most with game shortcuts, where the launcher window stays hidden.
- **Fixes.** Zenless Zone Zero (Mainland China) could show a blank captcha window at login. MacGacha now clears the game's saved WebView render setting before each launch. Game settings no longer grow taller than the launcher window. They scroll instead and follow the window when you resize it.
