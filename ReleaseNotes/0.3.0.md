# MacGacha 0.3.0

- **MacGacha Wine 11.20.** Our own Wine build, made from source, is now the recommended Wine for both DXMT and D3DMetal. Wine and the graphics layer are separate downloads, and D3DMetal still needs Apple's terms or your own Game Porting Toolkit.
- **Automatic dependency updates.** MacGacha installs new recommended versions of Wine and other dependencies in the background and switches to them once no game or download is running. Versions you choose by hand stay as they are. You can turn this off in Settings.
- **Old versions clean up after themselves.** The version an update replaced stays installed until a game has run on the new one for at least two minutes and closed normally. Then MacGacha removes it. Shared components and versions you pinned stay.
- **Imported Game Porting Toolkit.** Wine updates keep your imported D3DMetal. A newer D3DMetal is offered instead of installed, and skipping it only skips that version.
- **Redesigned Dependencies.** Each graphics layer has a Wine Version list with Automatic and every compatible build, so rolling back is one click. Rows show the build version, and background updates show their progress on the card.
- **Signed dependency list.** MacGacha only accepts a dependency list signed with the project's key.
- **Steadier downloads.** Fast connections no longer pause for a second or two every few seconds while files are written to disk.

Switching to a new Wine build creates a fresh Wine prefix for each game. Settings stored there, such as Star Rail's saved frame rate, start fresh. Your game files and saved logins are not affected.
