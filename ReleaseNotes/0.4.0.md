# MacGacha 0.4.0

- **Honkai Impact 3rd.** Install, update, repair and play Honkai Impact 3rd on five servers: Europe & Americas, JP, KR, SEA and Traditional Chinese. Pick the server from the menu beside Play. Each server has its own installation, settings and play time. Version 9.1.0 starts on every server with the Wine 11.22 D3DMetal or DXMT runtime. Gameplay has been tested on Europe & Americas.
- **Petit Planet and Honkai: Nexus Anima.** The game list now shows both upcoming games with a link to pre-register.
- **Install Later.** When installing a game, choose **Install Later** and pick a start time. The download starts at that time once you're away from the Mac. If you come back, it keeps going.
- **Scheduled Downloads.** Choose **Queue Update** in a game's menu to update it later. In Settings, set the hours when queued downloads may run, and whether they wait for power or for you to step away. Turn on **Automatically queue game updates** to check the games you pick every few hours.
- **Quiet downloads.** Scheduled downloads run at low priority with fewer files at once, so the Mac stays cool and quiet at night. You can also give them their own speed limit. Downloads you start yourself run at full speed.
- **Staying awake.** With **Keep this Mac awake for scheduled downloads** on, MacGacha keeps the Mac from sleeping on power while a scheduled download waits or runs. The display can still turn off. Closing a laptop's lid still puts it to sleep, and MacGacha can't wake a sleeping Mac.
- **Launch Details.** MacGacha remembers the last setup each game ran well with. When a game fails to start, **Details** beside the error shows what changed since then. If the earlier setup is still installed, **Try Previous Configuration Once** starts the game with it.
- **Fixes.** Switching games now fades smoothly instead of flashing dark. The Honkai: Nexus Anima background shows again.
