# MacGacha 0.3.2

Draft runtime changes, pending live qualification and publication.

- MacGacha Wine 11.22 build 1.0 becomes the recommended Wine for DXMT and D3DMetal. Wine 11.20 and earlier versions remain available for explicit rollback.
- Wine 11.22 includes the upstream certificate correction. Its bundles no longer require the separate Wine 11.20 crypt32 component.
- Surround Sound has a separate Wine 11.22 module. Runtime updates and explicit rollback pair Wine with its matching audio module while preserving per-game preferences and version pins. Device and game audio acceptance remains pending.
