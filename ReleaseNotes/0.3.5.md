# MacGacha 0.3.5

- **Miliastra Sandbox.** Genshin Impact's Miliastra Wonderland editor can now be installed from the game menu, for Global and Mainland China. Once installed, MacGacha keeps it on the same version as the game and updates it in the background when a new version comes out. Pressing Play stops a background update first. Before this, updating the game left an older editor in place and test play could fail. MacGacha also switches the editor to software rendering, because its window stays blank under Wine otherwise.
- **If the game turns gray.** When the editor opens, Genshin Impact sometimes turns gray and stops responding. Quit the game and start it again. It usually works on the next try. We're looking into the cause.
- **Clearer startup failures.** When a game can't reach its servers, for example on school or work Wi-Fi that blocks them, the footer now says so instead of only reporting that the game closed. Launch failures show in a highlighted capsule with Open Log, and the version and play time stay visible.
- **Fixes.** The background video no longer plays fast after the launcher was in the background for a while.
