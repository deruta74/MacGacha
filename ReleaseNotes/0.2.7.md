# MacGacha 0.2.7

Draft for the upcoming release. Final user-facing notes will be completed after the Dependencies redesign and runtime integration are verified.

## Integration draft for the next app release

- The Dependencies window groups runtimes, compatibility components and extras, with a version list for rollback.
- MacGacha Wine 11.20, build 1.0, is recommended for DXMT and D3DMetal. Wine and graphics remain separate downloads.
- Existing runtime versions remain available. Setup activates a new version only after its installation is verified.
- Switching Wine bundles creates a fresh prefix. Per-prefix settings such as Star Rail’s saved frame rate start fresh.
- Older apps accept catalog r2 for DXMT. They reject r3 and keep their cached catalog until the app is updated.

This remains a draft. The app version is unchanged. Owner live qualification,
app tests and release publication are still required.
