# MacGacha 0.2.7

Draft for the upcoming release. Final user-facing notes will be completed after the Dependencies redesign and runtime integration are verified.

## Integration draft for the next app release

- The Dependencies window groups runtimes, compatibility components and extras, with a version list for rollback.
- MacGacha Wine 11.20, build 1.0, is recommended for DXMT and D3DMetal. Wine and graphics remain separate downloads.
- Dependency updates run automatically by default for installed versions set to Automatic. You can turn this off in Settings. Versions chosen by hand stay pinned.
- Games use the current version while an update is prepared. A new version activates after installation is verified and games and other operations finish.
- The replaced version stays until a game runs for at least two minutes and finishes normally on the new one. Shared components and pinned versions stay installed.
- Wine updates preserve imported GPTK graphics. New D3DMetal versions are offered first, and skipping one does not hide later versions.
- Switching Wine bundles creates a fresh prefix. Per-prefix settings such as Star Rail’s saved frame rate start fresh.
- Older apps accept catalog r2 for DXMT. They reject r3 and keep their cached catalog until the app is updated.

This remains a draft. The app version is unchanged. Live qualification, app tests and release publication are still required.

- Dependency catalog downloads use an independent Ed25519 signature.
